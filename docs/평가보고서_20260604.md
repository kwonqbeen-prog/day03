### 2-2. 디자인 시스템

- **5종 팔레트**: 각 팔레트는 5가지 스와치 색상과 semantic 변수(primary/secondary/accent/support)로 분리 설계
- **다크모드**: 시스템 감지(`prefers-color-scheme`) + 수동 토글(`data-theme`) 이중 지원
- **팔레트 위젯**: 3-dot 미리보기, ✓ 체크 인디케이터, localStorage 영구 저장

```
변수 계층 구조
palette-*.css → CSS Custom Properties
style.css      → 변수 참조 (색상 미기입)
index.html     → #palette-css 교체로 전체 테마 전환
```

## 4. 종합 평가

### 잘 된 점

1. **CSS 변수 아키텍처**: 팔레트 파일 1개 교체로 전체 테마가 바뀌는 구조는 확장성이 높다.
2. **다크모드 이중 지원**: 시스템 설정 자동 감지 + 수동 토글을 동시에 지원하는 방식은 UX 완성도가 높다.
3. **이력서 콘텐츠 충실도**: 2개 이력서 파일(PDF/DOCX)을 교차 검토하고 가장 최신 정보(헤이그라운드 CX스태프 퇴사)를 추가 반영했다.
4. **검증 프로세스**: Playwright로 실제 브라우저에서 스크린샷을 찍어 JS 효과 정상 동작을 객관적으로 확인했다.
5. **자동화**: 초기 설정 이후 `git push` 한 번으로 배포까지 자동화되었다.

### 개선 여지

1. **번들 최적화 없음**: CSS/JS 미니파이·압축 미적용. 트래픽이 많지 않은 개인 사이트이므로 현재는 큰 문제 없으나, Lighthouse 점수 향상을 원한다면 추후 도입 권장.
2. **OG 이미지 팔레트 연동 미구현**: OG 이미지는 Sky Blush 고정. 동적 OG 이미지는 서버사이드가 필요하므로 정적 사이트의 구조적 한계.
3. **포트폴리오 심화 콘텐츠**: 현재 이력 목록 중심. 프로젝트별 상세 페이지, 작업물 이미지 추가 시 임팩트 상승 예상.
4. **`color-mix()` 브라우저 호환성**: Chrome 111+, Firefox 113+, Safari 16.2+ 이상 필요. 구형 브라우저 폴백 미처리.
