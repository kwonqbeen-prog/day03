## 3. 사용 기술 스택

| 분류 | 기술 |
|------|------|
| **마크업** | HTML5 Semantic |
| **스타일** | CSS3 (Custom Properties, Grid, Flexbox, `@media`, `color-mix()`) |
| **스크립트** | Vanilla JavaScript (ES6+, Canvas API, IntersectionObserver, localStorage) |
| **폰트** | Google Fonts — Noto Sans KR, Inter |
| **CI/CD** | GitHub Actions (`actions/deploy-pages`) |
| **호스팅** | GitHub Pages |
| **이미지 생성** | Playwright (Node.js) |

## 4. 이슈 & 해결

| 이슈 | 원인 | 해결 |
|------|------|------|
| `gh` CLI 미설치 | GitHub CLI 없음 | GitHub Actions 워크플로우로 대체 |
| PowerShell에서 한글 커밋 메시지 오류 | 쉘 인코딩 문제 | ASCII 메시지로 대체 |
| WebFetch가 HTML 구조 분석 불가 | 마크다운 변환 | Playwright로 직접 DOM 검증 |
| Canvas OG 이미지 폰트 미적용 위험 | 웹폰트 로딩 지연 | 시스템 폰트 스택 + `waitForTimeout(500)` |
